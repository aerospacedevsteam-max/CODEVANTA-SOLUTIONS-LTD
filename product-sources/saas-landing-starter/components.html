Component guide

Every section of the landing page is a self-contained block. Copy the HTML between its <!-- ===== Name ===== --> comments in index.html, keep the shared stylesheet, and include the scripts listed for that block. Blocks without JavaScript work on their own.

Design tokens

All colours, type sizes, radii and spacing are custom properties in the single :root block at the top of assets/css/styles.css. Change the brand colour once and every button, badge and focus state follows.

:root {
  --color-primary: #3b3fc4;       /* buttons, links, highlights */
  --color-primary-hover: #2e31a3; /* keep 4.5:1 contrast with white */
  --color-accent: #0d7d6c;        /* eyebrows, ticks */
  --font-sans: system-ui, ...;    /* swap in a self-hosted font */
  --radius: 12px;
}

When you change a colour, re-check text contrast (4.5:1 for body text, 3:1 for large text and UI outlines).

Header & mobile nav

Classes
.site-header, .nav-toggle, .primary-nav
Script
main.js (initNav)
Breakpoint
Menu collapses below 900px

The toggle button must keep aria-controls pointing at the nav’s id. The script updates aria-expanded and the button label, closes on Esc and returns focus to the button. Without JavaScript (no-js class on <html>) the links are shown inline.

<button class="nav-toggle" type="button" data-nav-toggle
        aria-expanded="false" aria-controls="primary-nav" aria-label="Open menu">…</button>
<nav id="primary-nav" class="primary-nav" aria-label="Primary">…</nav>

Hero with product UI mock

Classes
.hero, .hero-grid, .mock and .mock-*
Script
None

The mock is built from empty elements and one inline SVG, so it scales crisply and costs no image requests. It carries role="img" with a descriptive aria-label; update that label if you change what the mock shows. To use a real screenshot instead, replace the .mock element with an <img> that has meaningful alt text and explicit width/height.

Logo cloud (placeholder)

Ships as six dashed placeholder slots with a heading that says so. Only add logos of organisations that have agreed to be shown. Replace each <li class="logo-slot"> text with an SVG or image whose alt is the organisation name, and change the heading to something like “Trusted by teams at”.

Feature grid

Classes
.feature-grid, .feature-card, .feature-icon
Layout
Auto-fit grid, minimum card width 16rem
<li class="feature-card">
  <div class="feature-icon"><svg aria-hidden="true" focusable="false" …>…</svg></div>
  <h3>Feature name</h3>
  <p>One or two sentences.</p>
</li>

Icons are decorative (aria-hidden) because the heading carries the meaning. Icons use currentColor, so they follow --color-primary.

Alternating media rows

Each .media-row has a text column and a <figure class="media-figure">. Add .is-reversed to put the figure first on wide screens; on small screens text always comes first so reading order matches visual order. Meaningful SVG illustrations use role="img" plus a <title> referenced by aria-labelledby; every id must stay unique when you duplicate a row.

Pricing table with monthly/yearly toggle

Scripts
pricing.js then main.js (initPricing)
Config
data-discount (percent) and data-currency (ISO code) on the toggle wrapper; data-plan-monthly on each plan
<div data-billing-toggle data-discount="20" data-currency="USD">
  <fieldset class="billing-toggle">…two radio inputs named "billing"…</fieldset>
</div>
<li class="plan" data-plan-monthly="18">
  <span class="plan-amount" data-plan-amount>$18</span>
  <p class="plan-billing" data-plan-note>Billed monthly</p>
</li>

The toggle is a native radio group, so it is keyboard and screen-reader friendly without extra ARIA. A polite live region announces the change. Keep the monthly price in the HTML as the no-JavaScript fallback. Displayed prices are presentation only; your billing system remains the source of truth.

Comparison list

Two .compare-col cards; add .is-positive to the highlighted column. Avoid naming real competitors unless your claims are accurate and you have checked the legal position in your market.

FAQ accordion

Script
main.js (initAccordion)
Keys
Enter/Space toggle, ↑/↓/Home/End move between questions
<div class="faq" data-accordion>
  <div class="faq-item">
    <h3><button class="faq-trigger" type="button" id="q1"
        aria-expanded="false" aria-controls="a1">Question</button></h3>
    <section class="faq-panel" id="a1" aria-labelledby="q1"><p>Answer</p></section>
  </div>
</div>

Panels are visible when JavaScript is off; the script hides the ones whose button says aria-expanded="false".

Final CTA

.cta-band on a dark surface with .btn-light and a light-coloured .btn-outline. If you change --color-dark, confirm the text still meets contrast.

Footer

Auto-fit columns. Each link group is a <nav> labelled by its heading so screen-reader users can tell the landmarks apart. The year is filled in by main.js from any element with data-year.
