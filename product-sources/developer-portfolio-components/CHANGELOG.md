# Changelog

## 1.0.0 — initial release

- `<cv-hero>`, `<cv-project-card>`, `<cv-project-grid>` (tag filtering with keyboard
  support), `<cv-skill-list>` (chips and meter variants), `<cv-timeline>` /
  `<cv-timeline-item>`, `<cv-contact-form>` (client-side validation, `cv-submit`
  event) and `<cv-theme-toggle>` (light/dark, remembered choice).
- Shared `theme.css` with `--cv-*` custom properties for light and dark themes.
- Pure helper module `utils.js`.
- Demo page and documentation for every component.
