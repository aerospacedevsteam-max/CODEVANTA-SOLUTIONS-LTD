# Changelog

## 1.0.0 — initial release

- Workbook with Start Here, Dashboard, Settings, Income, Expenses, Monthly Summary
  and Category Summary sheets.
- Income and Expenses are Excel Tables with drop-down categories, payment methods
  and tax-deductible flags.
- Configurable financial-year start month and year, with 12-month summary.
- Category totals with percentage share and an "Uncategorised / other" check row.
- Dashboard with key totals, expense ratio, profit margin, best/worst month and a
  formula-driven bar visual.
- Fictional sample data (to be deleted before use).
