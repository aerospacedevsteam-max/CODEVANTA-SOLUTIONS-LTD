# Small Business Finance Tracker

An Excel workbook for recording one financial year of income and expenses, with
automatic monthly, category and dashboard summaries.

**File:** `Small-Business-Finance-Tracker.xlsx`

## Compatibility

Built for Microsoft Excel 2016+ and compatible spreadsheet apps; formulas verified with an automated recalculation test.

The workbook contains no macros, no external links and no dynamic-array functions
(no XLOOKUP, FILTER, LET, etc.). It uses standard functions only: `SUMIFS`,
`COUNTIFS`, `SUM`, `MAX`, `MIN`, `INDEX`, `MATCH`, `DATE`, `YEAR`, `MONTH`, `IF`,
`ROUND` and `REPT`. Charts are not used; the dashboard draws its bars with a
formula (`REPT("█", ...)`) so they show up in any spreadsheet app that supports those functions.

## Before you start: sample data

The workbook comes with **15 fictional income rows and 15 fictional expense rows**
so you can see how it works. Each one is labelled `SAMPLE` in the Description and
Notes columns. **Delete them before you enter real figures:**

1. Open the **Income** sheet and select the sample rows inside the table.
2. Right-click and choose **Delete > Table Rows**.
3. Do the same on the **Expenses** sheet.

The table headers, drop-downs and formatting stay in place.

## Sheet-by-sheet guide

| Sheet | What it is for |
| --- | --- |
| **Start Here** | Instructions inside the workbook. |
| **Dashboard** | Total income, total expenses, net profit, expense ratio, profit margin, average monthly net, best and worst month (by net), tax-deductible spend, entry counts, a warning count for entries dated outside the financial year, and a month-by-month bar visual of income vs expenses. |
| **Settings** | Business name, currency label, financial-year start month (1-12) and start year, plus the income category, expense category and payment-method lists (20 slots each). The financial-year start and end dates are calculated from these. |
| **Income** | Excel Table `IncomeTable`: Date, Client, Category (drop-down from Settings), Description, Amount, Payment method (drop-down from Settings), Notes. |
| **Expenses** | Excel Table `ExpensesTable`: Date, Supplier, Category (drop-down from Settings), Description, Amount, Tax deductible (Y/N drop-down). |
| **Monthly Summary** | 12 rows starting at your financial-year start month: income, expenses, net and cumulative net. It uses `SUMIFS` on the Date and Amount columns, with each month's start date and the next month's start date as the limits. |
| **Category Summary** | Total and % share for each income and expense category within the financial year. Amounts whose category is not on the Settings list are shown in an "Uncategorised / other" row (highlighted when it is not zero), so the totals always add up. |

Shaded cells contain formulas. Please don't type into them.

## Everyday use

- **Add a row:** type in the first empty row directly under a table. Excel extends
  the table automatically, and the drop-downs and number formats already apply.
- **Capacity:** the summaries read rows 5 to 1000 on Income and Expenses (996
  entries each). If you need more rows, edit the `$1000` row limit in the
  formulas on Monthly Summary, Category Summary and Dashboard (Find & Replace
  `$1000` with, for example, `$5000`).
- **Dates and amounts:** enter real dates and positive numbers without currency
  symbols. Data validation warns you about invalid entries.
- **Financial year:** set the start month and year on Settings. Entries dated
  outside that year are left out of every summary. The Dashboard counts them so
  you can spot typing mistakes. Use a new copy of the workbook for each year.
- **Currency:** the currency label is only a label. The workbook doesn't convert
  currencies.

## Adding or changing categories

1. Go to **Settings**.
2. Type a new category into an empty cell in the *Income categories* or
   *Expense categories* list (up to 20 each), or overwrite an existing one.
3. The new category appears in the drop-down on Income or Expenses and gets its
   own row on Category Summary straight away.

If you rename a category, existing rows that still use the old name are counted
under "Uncategorised / other" until you update them. The table filter on the
Category column makes them easy to find.

## How the formulas were checked

The workbook is generated by a script. A second script reopens the file,
recalculates every formula with a spreadsheet calculation engine and checks the
results against totals computed independently from the sample data. It also checks
these situations:

- a financial year that starts in another month
- an empty year
- a new row with an unknown category
- a newly added category
- all sample data deleted

In every case, no formula returned an error. Cached results are stored in the
file, and the workbook is set to recalculate fully when it opens.
