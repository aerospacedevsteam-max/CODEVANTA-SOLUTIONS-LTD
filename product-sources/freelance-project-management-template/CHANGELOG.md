# Changelog

## 1.0.0 — initial release

- Workbook with Start Here, Overview, Clients, Projects and Tasks sheets.
- Clients, Projects and Tasks are Excel Tables with drop-down IDs, statuses and
  priorities.
- Client-name lookup (INDEX/MATCH), % complete from tasks, days to deadline and
  days overdue calculated automatically.
- Overview with counts by status and priority, overdue and upcoming counts
  relative to a report date (=TODAY() by default) and a configurable window.
- Conditional formatting for overdue items, deadlines and statuses.
- Fictional sample data (to be deleted before use).
