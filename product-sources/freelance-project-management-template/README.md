# Freelance Project Tracker

An Excel workbook for tracking clients, projects and tasks. It shows overdue work
and upcoming deadlines automatically.

**File:** `Freelance-Project-Tracker.xlsx`

## Compatibility

Built for Microsoft Excel 2016+ and compatible spreadsheet apps; formulas verified with an automated recalculation test.

The workbook contains no macros, no external links and no dynamic-array functions
(no XLOOKUP, FILTER, LET, etc.). Client names are looked up with `INDEX`/`MATCH`.
Counts use `COUNTIFS` and `SUMIFS`. The report date uses `TODAY()`.

## Before you start: sample data

The workbook includes fictional **sample clients, projects and tasks**. Names end
in "(sample)" and client notes start with "SAMPLE". **Delete them before use.**
Select the sample rows inside each table, right-click and choose
**Delete > Table Rows**. Work through Tasks first, then Projects, then Clients.

## Sheet-by-sheet guide

| Sheet | What it is for |
| --- | --- |
| **Start Here** | Instructions inside the workbook. |
| **Overview** | Report date (cell **B3**, `=TODAY()` by default) and upcoming window in days (cell **B4**, default 14). Tasks by status with their share, tasks by priority (all and open), projects by status, and projects by priority (all and open). Key metrics: total, open and overdue tasks, open tasks due in the window, most overdue task (days), tasks completed in the window, open projects, open projects past their deadline, project deadlines in the window, budget of open projects and average % complete. |
| **Clients** | Excel Table `ClientsTable`: Client ID, Client name, Contact person, Email, Notes. |
| **Projects** | Excel Table `ProjectsTable`: Project ID, Project name, Client ID (drop-down from Clients), Client name (looked up), Start date, Deadline, Budget, Status, Priority, % complete and Days to deadline. The last three are calculated. Status options: Planned / Active / On hold / Completed / Cancelled. Priority options: Low / Medium / High / Urgent. |
| **Tasks** | Excel Table `TasksTable`: Task, Project ID (drop-down from Projects), Owner, Status (Not started / In progress / Blocked / Done), Priority (Low / Medium / High / Urgent), Due date, Done date and Days overdue (calculated). |

Shaded cells contain formulas. Please don't type into them.

## How the calculations work

- **Overdue task:** the status isn't Done and the due date is before the report
  date. *Days overdue* = report date − due date. Done tasks show 0.
- **Open project:** any status except Completed or Cancelled.
- **% complete:** tasks marked Done ÷ all tasks for the project. A project with
  no tasks shows 0%.
- **Due soon / deadlines soon:** the date falls between the report date and the
  report date + window, inclusive.
- **Conditional formatting:**
  - Tasks: overdue rows are red. Done is green, Blocked is amber, In progress is
    blue and Urgent priority is bold red.
  - Projects: open projects past their deadline are red, deadlines inside the
    window are amber, and Status cells are colour-coded. % complete shows as a
    data bar.
  - Overview: counts of overdue and upcoming items are highlighted when they are
    above zero.

### Looking at a different date

Type a date into **Overview!B3** to see the position on that day. Type `=TODAY()`
again to go back to live mode. Change **B4** to widen or narrow the "upcoming"
window.

## Adding rows

- Type in the first empty row directly under a table. The table extends
  automatically. The calculated columns are already filled in down to row 1000,
  and the drop-downs apply.
- Calculations read rows 5 to 1000 on every data sheet. If you need more rows,
  use Find & Replace to change `$1000` to a larger number in the formulas, and
  copy the calculated columns further down.
- Keep Client IDs and Project IDs unique. The drop-downs on Projects and Tasks
  read the ID columns, so the spelling always matches. If a Client ID isn't found,
  the client name shows "Unknown client ID".

## Adding or changing list options

Status and priority options are built into the data-validation rules, which the
Overview counts depend on. To rename an option:

1. Edit the data validation for that column (**Data > Data Validation**).
2. Update the matching label on **Overview**. Overview counts read their labels
   from the cells next to them.

## How the formulas were checked

The workbook is generated by a script. A second script reopens the file,
recalculates every formula with a spreadsheet calculation engine and compares the
results with values computed independently from the sample data, using several
fixed report dates and windows. It also checks two situations:

- a project with an unknown client and no tasks
- all sample data deleted

In every case, no formula returned an error. Cached results are stored in the
file, and the workbook is set to recalculate fully when it opens.
